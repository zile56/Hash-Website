# HASH Software Consultants

Official website for **HASH Software Consultants** — AI, web, and mobile software consulting based in Islamabad, Pakistan.

## Tech Stack
- **Framework:** React 19 + TypeScript + Vite
- **Icons:** Lucide React
- **Styling:** Vanilla CSS with custom design tokens (`tokens.css`, `global.css`)
- **Package Manager:** `pnpm` exclusively

## Features
- **Architectural Dark Design System:** Obsidian canvas (`#050608` / `#0c0d10`), hairline dividers, and fluid SVG background vectors.
- **DAQ-Inspired Motion:** Frame-batched scroll parallax, active scroll-progress bar, cursor spotlights (`--mx`, `--my`), and smooth entrance reveals.
- **Interactive Automation Pad:** Real-time animated cycle of automated operations with 3D pointer tilt.
- **Filterable Work Showcase:** Filter projects by `All`, `Mobile`, `Web`, and `AI & Data`.
- **Dark-Themed Sticky-Note Reviews:** Single tactile review slip paired under each project card with smoked translucent tape and `Caveat` handwritten client signatures.
- **Comprehensive Sections:** Hero, Marquees, Services, Stats, Work, Testimonials, Case Study, Process, Industries, About, Team, Careers, FAQ Accordion, Contact, and Footer.

## Development & Build (pnpm Only)
```bash
# Install dependencies
pnpm install

# Start local development server
pnpm dev

# Typecheck and lint
pnpm lint

# Production build
pnpm build

# Preview production build
pnpm preview
```
